## Theme

東京・青山の商業地におけるオープン地図データの店舗情報の現地検証 ― Overture Maps の存在確率（confidence）は店舗の実在を予測できるか

## 1. 序論（Introduction）

### 1.1 背景

地図アプリや AI サービスが、Overture Maps などのオープンな店舗データ（POI：店や施設の地点データ）を使い始めている。一方で、店舗は数年で大きく入れ替わる。

Overture の店舗データには、その場所が実在する確からしさを 0〜1 で示す confidence 値が付いている。しかし、日本の店舗でこの値がどこまで当てになるかは、まだ確かめられていない。

### 1.2 リサーチクエスチョン

- **メインRQ**：Overture Places の confidence 値は、青山周辺の店舗が実際に存在するかをどの程度予測できるか
- **サブRQ1**：全体の実在率は何%か
- **サブRQ2**：confidence がいくつ以上なら信頼してよいか（しきい値）
- **サブRQ3**：誤りの種類（閉店、位置ずれ、名称違い、業種違い）はどれが多いか
- **サブRQ4**：同じ範囲の OpenStreetMap（OSM）と比べてどちらが正確か

### 1.3 仮説

| 番号 | 仮説 | 根拠 |
|---|---|---|
| H1 | 全体の実在率は6割前後である | ブラジルの先行事例が63% |
| H2 | confidence 0.9以上なら9割以上が実在する | ブラジルの先行事例（0.9以上で95%） |
| H3 | 誤りの最多は「閉店したのに残っている」ことである | 店舗は数年で大きく入れ替わる |
| H4 | OSM は件数が少ないが、実在率は Overture より高い | 要確認 |

### 1.4 先行研究

1. **イギリスの Overture POI 分析**（[arXiv 2310.18415](https://arxiv.org/pdf/2310.18415)）
   スーパーの既存データと比べると、件数の差は5%未満、位置の差は平均6〜8mだった。業種・ブランドの欠けが多い。ただし、比較の相手は別のデータで、現地確認ではない。
2. **Klinkhardt ら（2023）による OSM の POI 品質評価**（Transportation Research Record, 2677(12), 661–674, [DOI: 10.1177/03611981231169280](https://doi.org/10.1177/03611981231169280)）
   大規模な実データで OSM の POI 品質を評価した。対象はドイツで、Overture は扱っていない。
3. **金杉・瀬戸・関本・柴崎（2019）による OSM 道路と市販道路地図の比較**（理論と応用, 27(1), 43–48, [J-STAGE](https://www.jstage.jst.go.jp/article/thagis/27/1/27_43/_article/-char/en)）
   日本の OSM は、地域によって網羅性や鮮度にばらつきがある。対象は道路。
4. **参考：Wille によるブラジル・サルバドールの分析**（[紹介元](https://community.openstreetmap.org/t/overture-maps-first-dataset-release/101702?page=3)）
   308件中63%が正しかった。confidence 0.6以上では81.2%、0.9以上では95%。個人による分析で、元記事は要確認。
5. **参考：マラガの5年間の POI 変化**（[OSM ダイアリー](https://api.openstreetmap.org/user/alan_gr/diary/405457)）
   5年で18%が消え、約4割に何らかの変化があった。個人の記録。

### 1.5 新規性

1. 日本の都市部で、Overture の confidence を現地確認によって検証する（同様の例は見つかっていない。要追加確認）
2. 正解データを、別のデータではなく自分の現地調査とする
3. 先行事例は初期のデータを調べている。本研究では最新版のデータを使い、どれだけ改善したかを確かめる（[Overture 公式ガイド](https://docs.overturemaps.org/guides/places)）

## 2. 方法（Methods）

### 2.1 対象範囲

青山学院から表参道・青山通り沿いの約500m四方。

### 2.2 サンプルの抽出

- Overture Places：confidence を4つの帯に分け、各帯から10件ずつ、計40件をランダムに選ぶ。

  | 帯 | confidence | 件数 |
  |---|---|---|
  | A | 0.5未満 | 10 |
  | B | 0.5〜0.7 | 10 |
  | C | 0.7〜0.9 | 10 |
  | D | 0.9以上 | 10 |

- OpenStreetMap：比較用に、同じ範囲から10件。
- 使用するデータのリリース版：要確認

### 2.3 現地調査

- 回数・時間：1回、約3時間（12月上旬）
- 記録する項目
  - 実在（あり／なし／移転／名称変更）
  - 業種の一致
  - 位置のずれ（m）
  - 店頭の写真（人が写らないように配慮する）

### 2.4 集計と分析

- confidence 帯ごとの実在率のグラフ
- 誤りの種類別の件数
- QGIS での地図化

### 2.5 生成 AI の活用

- 店頭写真とデータ上の店名が同じ店かどうかの判定に、生成 AI を補助的に使う（英語名とカタカナ名の表記ゆれへの対策）。
- 最終的な判断は人が行う。AI と人の判定の一致率も記録する。
- 使用する AI のサービス名・バージョン：要確認

### 2.6 評価指標

- 全体の実在率
- confidence 帯別の実在率
- 誤りの種類別の件数
- OSM との実在率の差
